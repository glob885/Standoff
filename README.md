# ОПЕРАЦИЯ «СИРЕНА» — 3D FPS про SCP-6789

Одиночный веб-шутер от первого лица: отряд MTF ε-11 из 50 бойцов, танки, БТР и
вертолёты против сиреноголового (SCP-6789). Работает на телефоне и на ПК прямо
в браузере — без установки, без внешних ассетов.

## Играть
Открой `index.html` через любой http(s)-хостинг (GitHub Pages / raw.githack).

## Управление
* **ПК:** клик — захват мыши · WASD — движение · мышь — обзор · ЛКМ — огонь ·
  ПКМ — прицел · R — перезарядка · Shift — бег · Esc — пауза
* **Телефон:** левый стик — движение · свайп справа — обзор · ОГОНЬ ·
  ◎ прицел · ⟳ перезарядка · ≫ бег

## Что внутри
* Three.js (r160, локально в `vendor/`), никаких CDN
* Процедурные текстуры (canvas), рельеф-heightmap, лес, трава с ветром
* Собственная пост-обработка: bloom, цветокоррекция, виньетка, зерно,
  радиальный blur во время крика босса
* Процедурный звук на WebAudio: выстрелы с эхом, взрывы, вой сирены, рация
* Кинематографичные катсцены, 2 уровня, 3 фазы боя с боссом
* Авто-настройка качества под слабые устройства

## Структура
```
index.html      разметка и HUD
style.css       интерфейс
main.js         загрузчик
src/util.js     математика, шум, пулы
src/textures.js процедурные текстуры
src/sky.js      небо и время суток
src/postfx.js   пост-обработка
src/world.js    рельеф, лес, трава
src/models.js   модели (боец, техника, босс)
src/fx.js       эффекты и частицы
src/audio.js    звук
src/entities.js сущности и ИИ
src/game.js     игровой цикл, уровни, катсцены
```
